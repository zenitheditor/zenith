Zenith fallback fonts
=====================

Four faces, in chain order. A Zenith provider tries them, in this order,
for a glyph the requested face lacks. All four are under the SIL Open Font
License 1.1 (see OFL.txt). Each name table states that license. Noto
declares no Reserved Font Name.

Tools: fonttools 4.54.1 (pyftsubset, fonttools varLib.instancer), Python 3.
Every command runs with SOURCE_DATE_EPOCH=1760227200, so the output bytes
are reproducible.
